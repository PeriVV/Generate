## 本轮实现与实际修复

- 统一任务取消上下文，贯通 HTTP 请求/响应读取、javac、测试 JVM 和 UI 销毁；取消不进入网络重试、模型修复或规则兜底。
- 不可变候选身份与证据关联源码、测试文本、SDK、依赖和配置输入；编译、运行、覆盖率及实际写入复核同一身份，输入变化使旧证明失效。
- 分离源码分析、后台快照、证据失效、写入前验证和 Swing 写入模式选择，注入执行边界；仅在当前任务内复用有效的环境导出，每个候选及最终文件仍分别编译和运行。
- 关闭类型探针 URLClassLoader，释放 Windows 依赖 JAR 句柄；覆盖成功、失败、取消、更换探针和重复使用。
- 修复 HTTP 总期限与读取期限竞争造成的异常类型变化；保留单阶段超时，总预算为三个阶段预算之和，持续响应仍有总期限。
- 修复无显式工作目录时旧 Windows JDK 损坏中文参数文件路径的问题。必要时以 ASCII 引用转存辅助启动文件，保留工作目录及应用参数，启动失败和退出后清理。
- 外部源码根不在项目 base path 内时，上层构建配置继续纳入快照。
- Surefire 外部系统属性文件作为显式输入追踪，配置复制保留清单；包括无扩展名且大小/修改时间未变的文件，按内容哈希检测变化。配置原值不进入证据或模型上下文。

实现过程与中间失败诊断见 [架构优化记录](architecture-refactor-1.0.52.md)。
